# Dead Leaves

Dead Leaves contains ideas that are abandoned, stale, or intentionally outside the current build. They are preserved so future LLM agents understand what was rejected without resurrecting it accidentally.

## Current REWIND dead leaves / excluded branches

Do not build these before the MVP gate unless explicitly reactivated by a new decision:

- autonomous robotics;
- centimeter-perfect placement;
- arbitrary whole-house understanding;
- multi-camera fusion;
- facial recognition;
- person identification;
- continuous human tracking;
- 24/7 raw video archives;
- SLAM / sophisticated indoor mapping;
- AR headset support;
- automatic smart-device actuation;
- complex billing;
- enterprise account systems;
- native mobile application;
- making commercial Ring Appstore publication a hackathon dependency.

These are not claims that the ideas are permanently worthless. They are **dead to the current MVP branch** because they weaken focus, reliability, privacy, or delivery speed.

## Reactivation rule

To revive a dead leaf:

1. create a new entry in `Knowledge/Decisions/`;
2. state why the old exclusion no longer applies;
3. define a gate and success metric;
4. update `PROJECT_STATE.md`.
