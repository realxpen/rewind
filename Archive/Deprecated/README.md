# Deprecated

Place approaches here when they are intentionally retired and should not be used in new work.

Current examples of behavior that are effectively deprecated for REWIND:

- using the AWS root identity for routine development;
- letting an LLM perform the canonical image-to-image diff;
- storing AgentCore conversational memory as canonical physical checkpoint truth;
- exposing Ring credentials or tokens client-side.

If a deprecated approach becomes useful again, require an explicit decision entry before restoring it to active Knowledge.
