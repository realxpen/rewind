# Archive

Archive preserves project history without allowing stale material to act as current truth.

## Sections

- `Superseded/` — once-valid approaches replaced by a newer decision.
- `Deprecated/` — approaches intentionally retired and not to be used.
- `Experiments/` — completed spikes, trials, and setup experiments retained for learning.
- `Dead-Leaves/` — abandoned, stale, or intentionally excluded branches of thought that should not influence the active build unless explicitly reactivated.

## LLM rule

**Never treat Archive as active project truth.** Consult it only for history, lessons, regressions, or an explicit request to revisit an old direction.

Archive items should explain why they were archived and what replaced them where applicable.
