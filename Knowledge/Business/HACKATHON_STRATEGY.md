# Hackathon Strategy

Hackathon: **Build, Ship, Shape: Amazon Developer Hackathon**.

## Track strategy

- Primary: **Ring**.
- Additional: **Alexa+** only after compliant MCP integration works.
- Mini-challenges: **AWS Builder + Open Source**.

## Why Ring

REWIND demonstrates a creative non-security Ring use case: physical-state memory and restoration rather than ordinary security alerts.

## AWS Builder story

Target multi-service architecture:

Ring → Nova/Bedrock → PSP/deterministic engine → Strands → AgentCore → verification.

The stronger story is an integrated AWS workflow, not a single model call.

## Open Source story

Open-source **Physical State Protocol v0.1** with schema, TypeScript types, normalization, deterministic diff engine, restore planner, fixtures, tests, docs, and examples.

## Submission priorities

- working repeatable demo;
- actual Ring runtime use;
- public GitHub repo and visible open-source license;
- under-three-minute public English demo video;
- Amazon product feedback;
- friction log;
- AWS integration explanation;
- open-source contribution explanation.

## Judging alignment

Optimize for:

1. Technical Implementation
2. Design
3. Potential Impact
4. Quality of Idea

Do not sacrifice demo reliability for breadth.
