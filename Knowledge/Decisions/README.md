# Decisions

This directory records **locked project choices** so future LLM agents do not repeatedly reopen settled questions.

A decision entry should include:

- date;
- status (`LOCKED`, `REVISIT`, `SUPERSEDED`);
- decision;
- rationale;
- consequences;
- replacement if superseded.

When a decision is superseded, keep the current decision here and move the obsolete reasoning/artifact to `Archive/Superseded/`.
