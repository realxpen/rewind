# Product Vision

## Product

**REWIND — Ctrl+Z for reality.**

Category: Spatial AI / Ambient Intelligence / Physical-State Computing.

## Core idea

Computers can save, compare, undo, restore, and inspect history. REWIND introduces analogous primitives to physical spaces.

A user saves a semantic checkpoint of a room, lets reality change, compares the current state against the checkpoint, receives a restoration plan, performs the actions, and lets REWIND visually verify completion.

Core loop:

**SAVE → CHANGE → DIFF → REWIND/RESTORE → VERIFY**

Humans remain the actuator. REWIND provides perception, memory, structured state, comparison, guidance, and verification.

## Product abstraction

The central abstraction is the **Physical State Checkpoint**.

A physical space can have:

- semantic state;
- named checkpoints;
- versions/history;
- meaningful differences;
- restoration plans;
- verification.

## Specific contribution

Use this positioning rather than unsupported `first-ever` claims:

> A conversational physical-state restoration system that captures semantic checkpoints, computes meaningful physical differences, generates restoration actions, and visually verifies that the environment has returned to its intended state.

## North star

Reject work that does not strengthen this moment:

User changes reality → REWIND sees the change → understands the difference → tells the user how to restore it → reality changes again → REWIND verifies it → **RESTORED**.
