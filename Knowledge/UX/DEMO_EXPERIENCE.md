# Demo Experience

## Demo payoff

The demo must prove the loop rather than explain it abstractly.

Open on the messy room and immediately trigger:

`Alexa, rewind the studio to Demo Ready.`

Then surface **6 CHANGES**.

Canonical changes:

- chair moved;
- headphones moved;
- backpack moved;
- tripod missing;
- desk cluttered;
- lamp off.

## Magic moment

The essential sequence is:

**human action → camera observation → state recomputation → progress changes automatically**

Show several real verification steps, then finish on:

**100% MATCH — DEMO READY RESTORED**

## Three-minute structure

- 0:00–0:10 — messy room + rewind request.
- 0:10–0:35 — six-change diff.
- 0:35–1:20 — execute/verify several restore actions.
- 1:20–1:35 — final action + 100% restored.
- 1:35–2:05 — fast architecture.
- 2:05–2:30 — open-source PSP.
- 2:30–2:50 — future use cases.
- 2:50–3:00 — REWIND / Ctrl+Z for reality.

No biography, long logo animation, setup screens, or waiting time in the opening.
