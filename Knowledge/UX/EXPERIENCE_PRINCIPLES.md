# Experience Principles

## Design metaphor

REWIND should feel like **version control for reality**, not a generic smart-home dashboard.

Use vocabulary and visual motifs such as:

- STATE
- CHECKPOINT
- DIFF
- REWIND
- RESTORED
- checkpoint timeline
- before/current comparison
- semantic diff cards
- progress ring
- spatial relationship labels
- version identifiers
- subtle camera overlays

## UX priorities

1. Make the physical state legible.
2. Make differences explainable.
3. Turn machine differences into simple human actions.
4. Show verification after action, not merely instruction.
5. Never fabricate certainty for visual drama.
6. Keep runtime integration evidence available for judges.

## Privacy as experience

Communicate the principle:

**Remember the state. Forget the footage.**

Target visible indicators:

- Raw image retention: OFF
- Semantic checkpoint retention: ON

## Consumer screens

- Space Dashboard
- Live Observe
- Save Checkpoint
- Physical Diff
- Rewind Mode
- Restored
- Debug/Judge Screen
