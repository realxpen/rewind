# Raw

Raw is REWIND's intake layer for evidence that has not yet been promoted into validated project knowledge.

Store here:

- project-chat notes and transcripts;
- screenshots and console observations;
- copied research and links;
- experiment output;
- rough ideas and prompts;
- Amazon/Ring/Nova/Alexa setup observations;
- temporary implementation notes.

Raw content is **not automatically current truth**. Validate it before using it to make architectural or product decisions.

Lifecycle:

`Capture → Raw → Validate → Knowledge → Apply → Test → Update or Archive`

Do not store credentials, OAuth tokens, access keys, passwords, or secrets here.
